# Claims

This folder is the investigation track for seemingly credible cure claims. Start at [`INDEX.md`](INDEX.md). Use [`TEMPLATE.md`](TEMPLATE.md) for a new file.

Evidence decides. Outline files do not announce that a claim is proved or disproved. Simulation plans are candidates only; installs need a separate owner OK.

Organize every claim **per cancer type and body site**. Do not treat a claim as a universal cure for cancer. If a claimant states it that way, quote the wording and still file the evidence by type and site. See the per-case rule in [`METHOD.md`](../METHOD.md).
