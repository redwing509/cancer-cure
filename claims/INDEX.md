# Cure claims — index

Seemingly credible cure claims are listed here, one file per claim. See [`TEMPLATE.md`](TEMPLATE.md) and [`METHOD.md`](../METHOD.md).

**This is not medical advice.** Read the [disclaimer in the README](../README.md). A claim’s presence in this index is not an endorsement, and an outline file is not a conclusion.

Each file records the claim, who makes it, quoted and linked evidence for and against, an evidence level, and a **simulation plan**. The simulation plan may name an open-source tumor-growth, pharmacokinetic, or similar model as a candidate. **Installing or running any model needs a separate OK** from the repository owner.
