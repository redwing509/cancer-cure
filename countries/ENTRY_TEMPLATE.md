# Entry template

Copy the block below for each study. One study per block. Split mixed papers (for example a mouse experiment plus a human trial) into separate entries, or label each result clearly so an in vitro or animal result is not read as a human result.

See [`METHOD.md`](../METHOD.md) for the evidence scale, the per-case rule, and citation rules. **Cancer type** and **body site** are required on every entry. See the [README disclaimer](../README.md): this is not medical advice.

```md
### <Compound or therapy>

- **Compound or therapy:**
- **Cancer type:**
- **Body site:**
- **Country:**
- **Study type:**
- **Population:**
- **Measured result (quoted):** ""
- **Link or DOI:**
- **Evidence level:** in vitro | animal | case report | observational | early trial | RCT | systematic review
- **Negative / null results:**
- **Source opened as:** full text | abstract only | not opened
```

## Field notes

- **Compound or therapy:** Use the name in the source. Keep the original-language name and add a short English gloss in parentheses when needed.
- **Cancer type:** Required. The disease name as the opened source uses it (for example hepatocellular carcinoma, or non-small-cell lung cancer). If the source studied more than one type, list each type or split the entry. If the source does not name a type, write `not stated in the opened source` and do not infer one. A result in one type is not a result in another.
- **Body site:** Required. The organ or anatomical site as the opened source uses it (for example liver, lung, or blood and bone marrow). Same rule: do not infer a site the source does not name. A finding at one site is not a finding at another.
- **Country:** The country of this note. If the work is a collaboration, name the partners and say where the study was done, as the source states it.
- **Study type:** The authors’ description of the design (for example “randomized, double-blind, placebo-controlled Phase III trial”).
- **Population:** Cell line, animal model, or clinical population, including counts, disease type, and stage when the source gives them. Copy; do not summarize into a stronger-sounding group.
- **Measured result (quoted):** A direct quotation of the outcome sentence, in quotation marks, in the source language or as printed in the English abstract you opened. Do not paraphrase a percentage or a p-value.
- **Link or DOI:** A legitimate link. Prefer a DOI landing page, PubMed, a trial registry, or an official repository. No piracy-site URLs.
- **Evidence level:** Exactly one value from the scale in METHOD.md.
- **Negative / null results:** Non-significant endpoints, harms, withdrawals, retractions, or “no effect.” If the opened source does not report any, write `not reported in the opened source`.
- **Source opened as:** Required so a reader knows whether the quote came from the abstract or the full paper.
