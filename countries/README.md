# Country notes

Each file in this folder is one country. Notes are added on a branch and opened as a pull request after the citations have been checked against opened sources. They are not merged to `main` automatically.

**This is not medical advice.** Read the [disclaimer in the README](../README.md) and the method in [`METHOD.md`](../METHOD.md). Use [`ENTRY_TEMPLATE.md`](ENTRY_TEMPLATE.md) for every study entry. **Cancer type** and **body site** are required. Follow the per-case rule in [`METHOD.md`](../METHOD.md): a result in one type or site is not a result in another.

Each country note should also list research programs and organizations that study cancer causes, and open-source tools we could run. Verified tools are copied to [`../tools/CANDIDATES.md`](../tools/CANDIDATES.md). Installs need a separate owner OK.
